## :dart: O guia para alavancar a sua carreira

## 🗺️ Roadmap

- [Electron — Process Model (documentação oficial)](https://www.electronjs.org/docs/latest/tutorial/process-model) — Explica os dois tipos de processo do Electron (main e renderer) e como eles se comunicam — a base para entender qualquer app Electron.
- [Electron Timelines](https://www.electronjs.org/docs/latest/tutorial/electron-timelines) — Calendário oficial de lançamentos: quando cada versão do Electron sai e por quanto tempo recebe suporte.
- [Releases do Electron no GitHub](https://github.com/electron/electron/releases) — Notas de lançamento de cada versão, incluindo as mudanças mais recentes de 2025 e 2026.
- [Blog oficial do Electron](https://www.electronjs.org/blog) — Anúncios de versões maiores, mudanças de segurança e novidades direto do time do Electron.
- [Governança do projeto Electron](https://github.com/electron/governance) — Como o projeto é organizado: grupos de trabalho, propostas e o processo de decisão open source do Electron.

**Trilha resumida** (siga na ordem; cada etapa tem recursos nas seções abaixo):

1. **JavaScript, HTML e CSS** — Electron não exige nada novo aqui: se você já constrói para a web, já sabe construir a interface de um app Electron.
2. **Node.js** — o processo main roda em Node.js puro, com acesso total ao sistema operacional (arquivos, rede, processos).
3. **Processo main × processo renderer** — o conceito mais importante do Electron: o main controla janelas e o sistema, o renderer mostra a interface (é um Chromium).
4. **IPC (comunicação entre processos)** — como main e renderer trocam mensagens sem comprometer a segurança.
5. **Segurança** — `contextIsolation`, `sandbox` e `preload` scripts: por que existem e como usá-los corretamente.
6. **Empacotamento e distribuição** — electron-builder ou Electron Forge para gerar `.exe`, `.dmg` e `.AppImage`.
7. **Atualizações automáticas** — como manter o app do usuário sempre na versão mais recente.
8. **Alternativas** — conheça o Tauri antes de decidir: menor, mais rápido, mas com um núcleo em Rust.

## ⚡ Tauri — alternativa moderna

O [Tauri](https://tauri.app/) é hoje a alternativa mais discutida ao Electron: em vez de empacotar um Chromium inteiro dentro do seu app, ele usa o motor de renderização que já existe no sistema operacional (WebView2 no Windows, WebKit no macOS/Linux) e um núcleo escrito em Rust. O resultado costuma ser um instalador dezenas de vezes menor e um consumo de memória bem mais baixo — o custo é uma curva de aprendizado extra (Rust) e um ecossistema de plugins ainda menor que o do Electron. Vale a pena conhecer antes de começar um projeto novo.

- [Tauri — site oficial](https://tauri.app/) — Framework para construir apps desktop e mobile menores, mais rápidos e mais seguros com um front-end web e um núcleo em Rust.
- [Tauri — Getting Started](https://tauri.app/start/) — Guia oficial para criar seu primeiro app com Tauri 2.
- [Tauri — Pré-requisitos](https://tauri.app/start/prerequisites/) — O que instalar (Rust, dependências do sistema) antes de começar com Tauri.
- [Tauri — Arquitetura](https://tauri.app/concept/architecture/) — Como o Tauri funciona por dentro e em que ele se diferencia do modelo do Electron.

## 🤖 IA na prática

Um app Electron tem duas metades muito diferentes — o processo main (Node.js, acesso total ao sistema) e o processo renderer (um navegador) — e isso muda como você deve usar IA em cada uma.

**Para aprender**
- Peça para um assistente **explicar a diferença entre main e renderer com um diagrama em texto** e um exemplo mínimo de IPC entre os dois.
- Cole um erro de `contextIsolation` ou de `preload` e peça: *"explique por que isso quebra a segurança e mostre a forma correta"*.
- Peça **exercícios com gabarito** sobre tópicos específicos (criar um menu nativo, salvar preferências com electron-store, empacotar com electron-builder).

**Para trabalhar**
- Use [GitHub Copilot](https://github.com/features/copilot), [Cursor](https://cursor.com/) ou [Claude Code](https://code.claude.com/docs/en/overview) para escrever handlers de `ipcMain`/`ipcRenderer`, configurar o `electron-builder.yml` e gerar testes com Playwright.
- Peça para a IA **revisar seu preload script** contra a [checklist oficial de segurança](https://www.electronjs.org/docs/latest/tutorial/security) — é o arquivo mais sensível de um app Electron.
- Ao construir recursos de IA dentro do próprio app (chat, agentes), rode o SDK no **processo main** (Node.js) e exponha apenas uma API mínima e específica ao renderer via IPC — nunca dê a uma `webview` acesso direto a chaves de API ou ao sistema de arquivos.

**Limites e boas práticas**
- IA **inventa opções de API** do Electron e de módulos nativos, principalmente em versões recentes (Electron lança major várias vezes por ano). Confirme sempre na [documentação oficial](https://www.electronjs.org/docs/latest/).
- Ela tende a sugerir `nodeIntegration: true` no renderer "para simplificar" — isso é exatamente o que a checklist de segurança pede para evitar. Não aceite sem entender o motivo.
- Não cole tokens, chaves de API ou dados de clientes em ferramentas de IA sem checar a política da sua empresa — lembre que o processo main tem acesso irrestrito ao disco do usuário.

- [GitHub Copilot](https://github.com/features/copilot) — Autocomplete e chat com IA no editor; ajuda a escrever handlers de IPC e configurações do BrowserWindow mais rápido.
- [Cursor](https://cursor.com/) — Editor de código com IA construído sobre o VS Code — e, portanto, sobre o próprio Electron.
- [Claude Code](https://code.claude.com/docs/en/overview) — Agente de código no terminal: útil para depurar comunicação entre main e renderer e revisar preload scripts.
- [Model Context Protocol — SDK TypeScript](https://github.com/modelcontextprotocol/typescript-sdk) — Crie servidores MCP em TypeScript/Node.js — o mesmo runtime do processo main do Electron — para conectar seu app a assistentes de IA.
- [Anthropic TypeScript SDK](https://github.com/anthropics/anthropic-sdk-typescript) — SDK oficial para chamar os modelos Claude a partir do processo main (Node.js) do seu app Electron.
- [Vercel AI SDK](https://ai-sdk.dev/) — SDK TypeScript para adicionar recursos de IA (chat, streaming, tools) a um app Electron.
- [Publishing an Electron AI App to the Microsoft Store (dev.to)](https://dev.to/aykankomurcu/publishing-an-electron-ai-app-to-the-microsoft-store-everything-i-got-wrong-3jbb) — Relato prático de 2026 sobre os desafios reais de publicar um app Electron com IA embutida.
- [Documentação de segurança do Electron](https://www.electronjs.org/docs/latest/tutorial/security) — Releia a checklist de segurança antes de dar a um agente de IA acesso ao processo main — é lá que vivem os privilégios do Node.js.
